# Full Auto Assist v1.1.0

- Retains 31 supported weapons, including MLS-4X Commando and APW-1 Anti-Materiel Rifle SPECIAL.
- Preserves the approved three-cartridge HUD indicator: hidden for unsupported weapons, white for supported FAA OFF, yellow for supported FAA ON.
- Adds Eruptor Cadence Control at 27 RPM (slower), 28 RPM (balanced default), and 32 RPM (vanilla maximum cadence). FAA OFF preserves native hold-to-repeat behavior.
- Reduces HUD and runtime overhead. Normal live gameplay measured about 5–8 ms/s, below the 10 ms/s release ceiling. Repeated toggle-spam stress can briefly reach about 10–12 ms/s.
- ARC-3 Arc Thrower, PLAS-101 Purifier, PLAS-15 Loyalist, PLAS-39 Accelerator Rifle, and 40-K Meltagun remain intentionally unsupported pending separate validation.
