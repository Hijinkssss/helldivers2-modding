# Full Auto Assist v1.1.0 RC2 live checklist

Status: pending. This candidate has not been deployed or launched by the agent. Any installation/config edits and game launch are a separate user action. Preserve the current package/selection for rollback, select only RC2 core plus its intended options, and avoid conflicting FAA core or cadence resources. Never load RC1 and RC2 core together.

1. Enter a mission with a familiar assisted weapon. Confirm the original yellow three-cartridge glyph beside the lower-left ammo HUD. Toggle FAA OFF: it hides. Toggle ON: it returns. Swap to native-auto/unsupported: it hides; swap back: it returns. Check ship/mission, death/respawn, resolution and HUD scale transitions. Record a screenshot and any overlap/fade differences. There is no native ammo-parent fade binding in this candidate.
2. Inspect `%LOCALAPPDATA%/CowboyBingus/Helldivers2/Logs/HD2FullAutoAssist.log`. `hud_rc2` should name implementation `1.1.0-rc2`, a rising draw_update_calls count, the equipped resource/name, eligible=true, hud_visible=true, renderer_available=true, gui_created=true, rectangles=9, reason=visible, on_screen=true and world/coordinate data. The logger is capped at 120 records per load. `hud_visible` means conditional state, not proof of displayed pixels.
3. If absent, stop at that failure and save the log. Optional isolation, with the game closed: set `hud_probe_visible=true` in the FAA INI and relaunch. The same three cartridges should appear enlarged at screen center even for an unsupported weapon. This changes rendering only. Save the screenshot/log; close the game, restore `hud_probe_visible=false`, relaunch and reconfirm normal conditional visibility before accepting RC2. Do not leave the force probe enabled.
4. Equip Commando: verify the HUD shows active assistance. With FAA OFF, establish ordinary manual behavior; turn ON and hold Fire through the four-round load. Test both Balanced 120 RPM (default) and Full Auto 240 RPM as separate Arsenal selections. Check repeated legal rockets, prompt stop on release, guided and dumb-fire selection/behavior, empty/expendable behavior and supported -> unsupported -> supported swaps. FAA must not reload, replenish ammo, change guidance/mode or fire after release. The requested input cadences are 500 ms at Balanced 120 RPM and 250 ms at Full Auto 240 RPM; measure actual shot intervals separately and do not equate input attempts with accepted rockets.
5. Eruptor: select 28 RPM Balanced / default and verify hold/release across several bolt cycles. Repeat separate selections of 27 RPM Slower Cadence and 32 RPM Maximum Full Auto. Only these three options should appear. Requested intervals: 2.142857 / 2.222222 / 1.875 seconds respectively. Record animation/audio continuity and feel separately from accepted shot counts. Confirm default without INI or explicit Arsenal selection is 28. Old RC1 selections should migrate to the corresponding new cadence without disabling FAA.
6. Spot-check existing assisted sidearms/rifles and all selected profiles; verify OFF, release, swaps, ship and respawn restore behavior. Arc Thrower, Purifier, Loyalist, Accelerator, Meltagun, unknown and native-auto weapons remain FAA-unassisted. Disable separate automation mods if isolating vanilla behavior of excluded weapons.
7. Save observations, screenshots and log with package hash, settings, resolution and Loader/game build. Optional Watchdog checks must be described as live measurements; offline native-work parity is not a performance benchmark.

Accept only after normal conditional HUD visibility, Commando mechanics and all three Eruptor cadences are observed. If GUI coordinates are valid but no pixels appear, investigate world/draw ordering from the capture before changing glyph design.
