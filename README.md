# Helldivers 2 modding

**[Full Auto Assist 1.0.1](HD2FullAutoAssist/README.md)** is an accessibility-focused QoL mod for 30 explicitly supported weapons. It requires Bingus Shared Loader v18 / API 1 and supports Steam build 25480438 behind an exact-build gate. Unknown and native Full Auto weapons remain vanilla.

See the [release changelog](HD2FullAutoAssist/CHANGELOG.md), [Nexus release materials](HD2FullAutoAssist/docs/NEXUS_RELEASE.md), and [developer offline checks](HD2FullAutoAssist/tests/README.md).

## Repository contents

| Directory | Purpose |
|---|---|
| `HD2FullAutoAssist/` | Standalone mod source, release packaging, public documentation, and offline validation |
| `HD2ModCore/` | Separate framework and developer preview; not a Full Auto Assist dependency |
| `integrations/HD2ModCore-runtime-candidate/` | Separate experimental integration retained for reference checks |
| `validation/` | Historical research provenance and technical evidence; not an installable mod |
