# Helldivers 2 modding

**[Full Auto Assist 1.3.0](HD2FullAutoAssist/README.md)** is an accessibility-focused QoL mod for 31 explicitly supported weapons. Configure individual weapons and existing firing profiles in-game through the Mod Options Menu. Core firing requires Bingus Shared Loader v18+ / API 1 (v19 recommended) and supports Steam build 25480438 behind an exact-build gate. Unknown and native Full Auto weapons remain vanilla. For in-game settings, enable the Mod Options Menu and Mod Bindings Menu components from Vanilla Plus Megapack, or install their standalone versions. Use one copy of each menu.

See the [release changelog](HD2FullAutoAssist/CHANGELOG.md), [Nexus release materials](HD2FullAutoAssist/docs/NEXUS_RELEASE.md), and [developer offline checks](HD2FullAutoAssist/tests/README.md).
